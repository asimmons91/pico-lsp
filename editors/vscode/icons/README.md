# Extension and file icons

`pico-lsp.png` is original artwork created for this project. It depicts a
generic game cartridge with a rainbow label and a sparkle; it does not reproduce
the official PICO-8 logo or wordmark. The artwork is covered by the repository's
[MIT license](../../../LICENSE), like the rest of the project.

The editable SVG source is `../images/pico-lsp-icon.svg`. The rendered PNG is
128x128 with an alpha channel and is used both as the Marketplace/Open VSX
listing icon and as the default file icon for `.p8` carts in VS Code.

PICO-8 and the PICO-8 logo are trademarks of Lexaloffle Games. This project is
an independent project and is not affiliated with or endorsed by Lexaloffle.
The icon intentionally avoids Lexaloffle's logo and wordmark.
